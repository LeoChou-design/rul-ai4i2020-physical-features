# References

Full texts are not redistributed here (copyright belongs to the original
publishers/authors) — links are provided where a legitimate open-access copy
exists.

1. Matzka, S. (2020). Explainable Artificial Intelligence for Predictive
   Maintenance Applications. In *2020 Third International Conference on
   Artificial Intelligence for Industries (AI4I)*, pp. 69–74.
   https://doi.org/10.1109/AI4I49448.2020.00023 (IEEE Xplore, paywalled) —
   dataset paper, see `data/README_data.md`.

2. Lee, J., Wu, F., Zhao, W., Ghaffari, M., Liao, L., & Siegel, D. (2014).
   Prognostics and health management design for rotary machinery
   systems—Reviews, methodology and applications. *Mechanical Systems and
   Signal Processing*, 42(1), 314–334.
   https://doi.org/10.1016/j.ymssp.2013.06.004 (publisher, paywalled)

3. Physics-informed machine learning for remaining-useful-life estimation
   (background for the derived-feature approach used here):
   "Physics Informed Machine Learning (PIML) methods for estimating the
   remaining useful lifetime (RUL) of aircraft engines", open access:
   https://arxiv.org/abs/2406.15619

4. "Physics-Informed Machine Learning in Prognostics and Health Management:
   A Systematic Literature Review", open access: https://arxiv.org/abs/2608.10047

5. Ehrig, J., Atzberger, D., et al. Customizable Asymmetric Loss Functions
   for Machine Learning-based Predictive Maintenance. CMD 2020 — background
   for the asymmetric scoring function used in this study (penalizing
   "late warning" predictions more than "early warning" ones), open PDF:
   https://hpi.de/doellner/people/dr-jan-klimke/Document/jan.klimke/CMD2020.pdf
